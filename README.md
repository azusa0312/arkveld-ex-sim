# 護鎖刃龍 上位狩獵戰 練習場（FF14 × 魔物獵人荒野）

**線上版**：https://azusa0312.github.io/arkveld-ex-sim/

FF14 聯動副本「護鎖刃龍上位狩獵戰（The Windward Wilds (Extreme)）」的 3D 機制練習場。
你只控制自己的角色，其他 7 人是照攻略走位的 NPC；站錯會立刻停下並用中文說明原因。

攻略來源：B 站子言姐姐〈護鎖刃龍攻略 上位極神難度〉（BV15S1qBCEwn，日服野隊 ぬけまる G 式）＋ GAME8 文字攻略。

**操作**：WASD 移動、空白鍵跳躍、拖曳轉視角、滾輪縮放、Enter 開始／重來。

**自動模式**：設定面板勾「自動模式」，你選的職能也會照攻略自動跑（8 人全自動，看一遍示範），金色圈標出角色接下來要去的位置。

## 分組與場標

- 場標：A 北、B 東、C 南、D 西，中央 1。
- MT 組：MT・H1・D1・D2；ST 組：ST・H2・D3・D4。
- 白光／龍光（兩組分攤）：MT 組靠王、ST 組遠離王。
- 踩塔：MT 北（或西）大塔、ST 南（或東）大塔；小塔 D3 西北、D4 東北、D1 西南、D2 東南（整組跟著大塔方向旋轉）。
- 鎖刃躍動：王左手高 → 順時針，1/5 在 B、2/6 在 C、3/7 在 D、4/8 在 A；右手高 → 逆時針，1/5 在 D、3/7 在 B。

## 機制（全程順序＝影片開頭的固定時間軸）

**P1**：咆哮 → 鎖刃敲打 ×2 → 鎖刃飛翔突進＋白光／龍光 → 黃圈＋鎖哭龍閃 → 飛翔突進（第二次）→ 鎖刃敲打 ×2 →
突進＆龍閃 ×3 → 回旋鎖刃【龍閃】＋龍光擴散 → 甩尾突刺 → 鎖刃下揮 → 鎖刃敲打 ×2 → 咆哮 → 護龍共振（踩塔）＋黃圈 ×3 → 波狀龍閃＋龍光擴散

**P2**：護龍亂擊 → 鎖刃躍動（骰子）→ 踩塔＋黃圈 → 龍閃炮 ×3＋白光＋龍光擴散 → 鎖哭龍閃・改 → 之後重複 P1 的機制 → 咆哮 ×2 → 護龍亂擊（狂暴）

| 機制 | 怎麼躲 |
|---|---|
| 鎖刃敲打 ×2 | 先打王「舉手」那一側的半場，再打另一側：先站沒舉手側，第一下打完立刻換邊 |
| 鎖刃飛翔突進 | 白線【護龍共振】：線之後變粗，站線外分攤；紅線【龍閃】：兩側爆炸，突進後進中間直線分攤 |
| 黃圈＋鎖哭龍閃 | 散開放兩次黃圈；王前方的直線一格一格往前推，等前一格打完就走進去 |
| 突進＆龍閃 ×3 | 在第 3 個落點旁邊等，第 3 下打完走進它的圓圈（環形的內側安全） |
| 回旋鎖刃 | 打沒有尾巴的那一半；同時全員龍光擴散要散開 |
| 甩尾突刺 | 尾巴方向的直線 |
| 鎖刃下揮 | 全員分攤，之後原地爆炸要離開 |
| 護龍共振＋黃圈 ×3 | 黃圈不能放在塔上：近戰 中→外→中→進塔；遠程／治療 中→外→最外圈 |
| 波狀龍閃 | 步進圓形 AOE 從中央往外推，碰到結晶就爆炸；站斜角靠內側 |
| 鎖刃躍動 | 骰子 1～8 依序被撲；撲完回中間（王會打那一側的半場），5～8 號等前一人的半場打完再出去 |
| 龍閃炮 ×3 | 東 → 西 → 東；被點名的人在場邊引導、直線出現後往旁邊閃；第 2 發時其他人在東邊兩組分攤 |
| 鎖哭龍閃・改 | 十字 → 直線往外 → 往回 → 十字：第一次十字後走到正中央，最後再退到斜角 |

範圍大小、讀條時間、部分站位（例如甩尾方向、龍閃炮引導點）是依影片畫面推估的，不是官方數值。
